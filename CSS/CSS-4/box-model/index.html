The box-sizing: border-box; property is used to keep the total width and height of an element within the specified dimensions. In this example, the width is 350px, which already includes 20px padding on each side and a 5px border on each side. Therefore, padding and border do not increase the total width beyond 350px.


Width: 350px

Padding 20px

border: 5px

Output: 400px

The box-sizing: content-box; property sets the specified width and height for the content only. Padding and border are added outside the specified dimensions, increasing the total width and height of the element.
